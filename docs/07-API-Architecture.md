## Purpose

Define the external and internal API surfaces that expose research capabilities to clients while preserving transparency of evidence, confidence, and uncertainty.

## Audience

API designers, frontend engineers, and backend engineers integrating research sessions, workspaces, and report retrieval.

## Scope

In scope:

- API design principles aligned with Evidence Before Conclusions and Transparency Over Certainty
- Resource boundaries (sessions, evidence, reports, knowledge, workspaces)
- Sync vs. async research execution patterns
- Error, uncertainty, and partial-result semantics

Out of scope (for now):

- Concrete route tables and OpenAPI specs
- Authentication/authorization implementation
- Rate limiting and billing
