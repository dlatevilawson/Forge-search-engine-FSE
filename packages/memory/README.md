# `packages/memory`

## Owns

**Persistence and retrieval of research and knowledge over time.**

- Storing research artifacts and derived knowledge
- Retrieving prior knowledge for future sessions
- Supporting continuous learning / refresh of stored knowledge (capability, not necessarily a pipeline stage in v0.1)

## Does not own

- Report formatting or section assembly (`reporting`)
- Project/folder/collaboration UX models (`workspace`)
- Retrieval of external web/video sources (`search`)
- Verification or reasoning computation

## Logical pipeline stage(s)

- Knowledge Storage

## Notes

Project-scoped storage ownership vs `workspace` is **OPEN-3** in `docs/04b-Traceability-Matrix.md`.
