# `packages/reasoning`

## Owns

**Analytical reasoning over verified evidence:**

- Consensus detection / summarization
- Conflict analysis (surface and explain disagreement)
- Confidence assessment (including unknowns)

## Does not own

- Claim validation (`verification`)
- Retrieval (`search`)
- Report document assembly (`reporting`)
- Persistence (`memory`) or project/collaboration models (`workspace`)

- Conflict Analysis
